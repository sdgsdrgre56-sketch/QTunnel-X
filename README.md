# Квазар для Android (первая версия)

То же, что на ПК: ядро mihomo даёт локальный SOCKS5, режим TUN (VpnService + hev-socks5-tunnel) гонит через него весь трафик телефона. Приложение исключено из VPN, петли нет.
Протокол в этой версии: **Sudoku** (как у тебя на ПК, высокие порты). ПК-Квазар и серверы не тронуты.

## Как собрать APK
1. Создай на GitHub новый репозиторий (например `quasar-mobile`) и залей туда содержимое этой папки (ветка `main`).
2. Вкладка Actions → «Build Quasar APK» → Run workflow (или просто push). Через 5–10 минут внизу запуска будет `quasar-mobile-apk` → `app-debug.apk`.
3. Поставь APK на телефон (разреши установку из неизвестных источников).

## Как пользоваться
1. В ПК-Квазаре скопируй ссылку `quasar://…` сервера (с включённым Sudoku).
2. В приложении вставь её → «Взять Sudoku из ссылки» → «Подключить» → разреши VPN.
   Можно ввести адрес, порт и ключ руками.
3. Галочка «Российские сайты напрямую»: .ru, VK, Яндекс, Госуслуги, Rutube идут мимо туннеля (при белых списках они и так открываются).

## Не проверено (честно)
Собрать и запустить это в среде разработки было нечем (нет Android SDK и сети). Возможные места, где CI может споткнуться: имя файла ядра mihomo в релизе (в журнале шага печатается список), сборка hev-socks5-tunnel через ndk-build. Если сборка упала — пришли красный журнал шага.
