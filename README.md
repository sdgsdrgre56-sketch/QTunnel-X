# Квазар для Android

Полная копия ПК-Квазара: тот же код (Node.js внутри APK через nodejs-mobile) и тот же интерфейс в окне приложения. Вкладки, список серверов, «Мои серверы» (установка по SSH), маршруты, журнал, все ядра.
Режим TUN: на Android его поднимает приложение (VpnService + hev-socks5-tunnel), а sing-box работает локальным портом. Кнопка/переключатель «Туннель (TUN)» в интерфейсе включает его.

Что отличается от ПК: нет раздачи на приставку и системного прокси (Windows-функции); ядра лежат внутри APK и обновляются выходом новой сборки.
Ядра: sing-box, mihomo, Xray, NaiveProxy, Brook, usque, ShadowQUIC, Juicity кладутся при сборке (`tools/fetch-cores.sh`); Фотон и Antohin работают на самом Node. Если ядра нет в релизе под Android — оно пропускается, в журнале сборки видно какое.

Сборка: Actions → «Build Quasar APK» → артефакт `quasar-mobile-apk`.
`nodejs-project/` — код ПК-Квазара с небольшими правками под Android (все под флагом `QUASAR_ANDROID`).
